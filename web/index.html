ℹ️ About Smart File Organizer Web Edition

A zero-install, client-side web application for organizing cluttered directories without privacy leaks.

🔐 Privacy & Security

Unlike cloud converter services, Smart File Organizer Web Edition performs 100% client-side categorization and archiving. Your files are never uploaded to any remote server or third party.

⚡ Features

  • Drag & drop file or folder batch loading.
  • Real-time extension inspection and category mapping.
  • Automatic duplicate collision handling (report_1.pdf).
  • Bundled client-side ZIP packaging with manifest metadata.
  • Completely portable: run locally or deploy to static hosts like Vercel.
